1. O que o CSS faz — e o que o HTML faz

HTML marca significado: títulos, parágrafos, listas, links, formulários. O navegador precisa dessa árvore para acessibilidade e SEO. CSS decide apresentação: cor, ritmo, hierarquia, layout e movimento.

h1 { letter-spacing: -0.04em; }
.kicker { text-transform: uppercase; }

CSS3 é o nome popular do CSS moderno: módulos (seletores, flex, grid, animações, variáveis) em vez de um único “CSS 2.1 engessado”.

2. Anatomia de uma regra

seletor {
  propriedade: valor;
}

Uma folha é uma lista de regras. Comentários usam /* assim */. Várias propriedades no mesmo bloco; várias regras para o mesmo seletor se combinam na cascata.

3. Cascata, especificidade e herança

Quando duas declarações brigam, o vencedor segue esta ordem de desempate:

  1. Origem e importância — user-agent, usuário, autor; depois !important (evitar).
  2. Camadas — @layer deixa a ordem explícita.
  3. Especificidade — inline > id > classe/atributo/pseudo-classe > elemento.
  4. Ordem no código — a última declaração equivalente ganha.
SeletorEspecificidade (a,b,c)
h10, 0, 1
.card0, 1, 0
#aluno1, 0, 0
.nav a:hover0, 2, 1

Propriedades como color e font-family herdam. Margin, padding e border não. Use inherit, initial, unset ou revert-layer com intenção.

4. Seletores, pseudo-classes e pseudo-elementos

.card > p { }          /* filho direto */
.trilha .nivel { }     /* descendente */
a[href^="https"] { }   /* atributo */
li:nth-child(2n) { }   /* posição */
p::first-line { }      /* pseudo-elemento */
:focus-visible { outline: 2px solid; }

Prefira classes para componentes. IDs para âncoras e JS. Elementos para tipografia de documento. !important só em último caso (overrides de acessibilidade, por exemplo).

5. Box model, display e fluxo

Toda caixa tem content, padding, border e margin. Com box-sizing: border-box, width inclui padding e borda — o modelo previsível do CSS em Folhas.

*, *::before, *::after { box-sizing: border-box; }

.block { display: block; }     /* quebra linha, aceita width */
.inline { display: inline; }   /* flui no texto */
.ib { display: inline-block; } /* flui, mas aceita medidas */

margin vertical de blocos adjacentes pode colapsar. Flex e Grid não colapsam margin da mesma forma — mais um motivo para layout moderno.

6. Cor, unidades e tipografia

Unidades relativas respeitam o leitor: rem a partir do root, em a partir do pai, ch para largura de coluna. px para bordas finas. vw em texto longo pede clamp() para não estourar.

:root { font-size: 100%; }
h1 {
  font-size: clamp(2.4rem, 6vw + 1rem, 5.6rem);
  font-family: Syne, sans-serif;
  letter-spacing: -0.04em;
}
.kicker {
  font-family: "JetBrains Mono", monospace;
  letter-spacing: 0.22em;
  text-transform: uppercase;
}

Cores modernas: oklch(), color-mix(), gradientes lineares, radiais e cônicos. Contraste é UX: texto e fundo precisam se ler, não só “ficar bonito”.

color: oklch(0.72 0.12 230);
background: color-mix(in oklab, #0b1222 62%, transparent);
background: linear-gradient(125deg, #60a5fa, #a78bfa, #f472d0);

7. Flexbox — uma dimensão

O eixo principal segue flex-direction. justify-content alinha nesse eixo; align-items no eixo cruzado. gap substitui a maioria das margins entre irmãos.

.header-acoes {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  flex-wrap: wrap;
}
.nav {
  display: flex;
  justify-content: center;
}
.item { flex: 1 1 12rem; }

flex: 1 1 auto = cresce, encolhe, base automática. Wrapping transforma uma fileira em várias — ainda é um eixo, só que quebrado.

8. CSS Grid — duas dimensões

Grid define trilhas (colunas e linhas). fr reparte espaço livre. minmax() e auto-fit criam colunas que cabem sozinhas.

.conceitos {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
  gap: 1.5rem;
}
.aula-shell {
  display: grid;
  grid-template-columns: 16rem 1fr 18rem;
  grid-template-areas: "modulos player aside";
}

Áreas nomeadas documentam o layout. subgrid (quando o navegador cobre) alinha filhos ao pai. Para cartões numa dimensão, Flex costuma bastar; para página inteira, Grid.

9. Responsividade, fluid type e container queries

Mobile-first: o padrão é o estreito; @media (min-width: …) amplia. Container queries olham o pai, não a viewport — úteis em cartões reutilizáveis.

@media (max-width: 900px) {
  .hero { grid-template-columns: 1fr; }
}
@container (min-width: 28rem) {
  .card { grid-template-columns: 1fr 1fr; }
}

Tipografia fluida: clamp(mínimo, preferido, máximo). Evite vw puro em parágrafos longos — o zoom do usuário e o comprimento de linha sofrem.

10. Variáveis CSS, temas e tokens

Custom properties no :root são o design system vivo. Herdam. Mudam com JS (barra de status do CSS em Folhas: --conclusao, --xp-aluno).

:root {
  --ciano: #5eead4;
  --gutter: clamp(1rem, 3vw, 2rem);
  --easing: cubic-bezier(0.22, 1, 0.36, 1);
}
.btn { background: var(--aurora); }
[data-theme="claro"] { --texto: #12182b; }

Tokens de cor, tipo, espaço e motion. Um nome estável (--raio-pill) vale mais que um hex espalhado em 40 arquivos.

11. Transições, transforms e animações

Anime propriedades compostas na GPU: transform e opacity. Evite animar width/top em loops. Respeite prefers-reduced-motion.

.carta-3d {
  transform: perspective(900px) rotateY(-18deg) translateZ(24px);
  transition: transform 280ms cubic-bezier(0.22, 1, 0.36, 1);
}
.carta-3d:hover { transform: translateZ(42px) rotateY(0); }

@media (prefers-reduced-motion: reduce) {
  .cubo { animation: none; }
}

@keyframes para ciclos (cubo, aurora). Transição para interação (hover, foco). Transform 3D pede perspective no palco e transform-style: preserve-3d no objeto.

12. Seletores modernos, :has() e @layer

:has() estiliza o pai a partir do filho — o “seletor de pai” que o CSS esperou décadas.

form:has(:invalid:not(:placeholder-shown)) {
  box-shadow: inset 0 0 0 1px #fb7185;
}
.card:has(a:hover) { border-color: var(--ciano); }

@layer ordena a cascata: reset, base, layout, componentes, páginas. Utilitários por último. Assim um .card não precisa de especificidade inflada para vencer o reset.

@layer reset, base, layout, components, pages, utilities;

@layer components {
  .btn { border-radius: 999px; }
}

Checklist do projeto final

  • HTML semântico (um h1, landmarks, skip link).
  • Tokens no :root e tipografia com voz (display, serif, mono).
  • Layout com Flex + Grid, não float.
  • Foco visível, contraste, prefers-reduced-motion.
  • Camadas @layer e componentes previsíveis.
