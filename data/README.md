# data/

Dados de conteúdo em JSON, separados do JavaScript.

| Arquivo | Consumidor | Conteúdo |
| --- | --- | --- |
| `css3-atmosfera.json` | `js/features/atmosfera.js` | Técnicas do cubo (blur, mix-blend, variáveis) |

Se o `fetch` falhar, `atmosfera.js` usa um catálogo mínimo embutido. URL pública: `/data/css3-atmosfera.json`.
