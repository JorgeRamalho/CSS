# js/pages/

Um script por arquivo em `/pages`. Não misturar recursos da home aqui.

| Arquivo | HTML | Função |
| --- | --- | --- |
| `matricula.js` | `pages/matricula.html` | ViaCEP, persistência da ficha, toast de confirmação |
| `aluno.js` | `pages/aluno.html` | Perfil, progresso, avatar, anotações |
| `sala.js` | `pages/sala.html` | Módulos, iframe do YouTube, concluir aula |
| `jornada.js` | `pages/jornada.html` | Curva SVG, quizzes, laboratório |

Dependências: `js/core/data.js` e `js/core/app.js` já carregados.
