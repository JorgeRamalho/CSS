# js/features/

Recursos visuais da home. Cada arquivo tem uma folha correspondente em `css/`.

| Arquivo | Folha | Função |
| --- | --- | --- |
| `palco3d.js` | `css/efeito-3d.css` | Inclina o palco com o ponteiro; respeita `prefers-reduced-motion` |
| `estudio.js` | `css/estudio.css` | Roteiro de código + preview de artes CSS |
| `atmosfera.js` | `css/efeito-3d.css` | Lê `/data/css3-atmosfera.json` e aplica técnicas no cubo |

Não carregar estes scripts nas páginas internas.
