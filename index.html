Dois ofícios, uma página

Separar estrutura e apresentação é a primeira estratégia de desenvolvimento sustentável.

HTML

O esqueleto

Marca o significado: títulos, parágrafos, listas, links, formulários e mídia. O navegador precisa dessa árvore para acessibilidade e SEO.

<h1>CSS em Folhas</h1>

CSS

A apresentação

Pinta, alinha, anima e responde ao espaço. Gradientes, tipografia, grid e variáveis deste portal são CSS puro.

h1 { letter-spacing: -0.04em }

UX · UI

A experiência

Contraste, foco visível, skip link, hierarquia e barra de status: o estilo serve a leitura e a navegação, não o contrário.

:focus-visible { outline: 2px solid }

Portal de estudos · CSS3

CSS não é o esqueleto.
É a voz visual da web.

HTML organiza textos, imagens e links — o esqueleto. CSS decide como o navegador os exibe: cor, ritmo, hierarquia, layout e identidade.
